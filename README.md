# E-Commerce-Sales-Dashboard
An interactive, Power BI Dashboard built to track, analyze,
and visualize comprehensive e-commerce sales performance, customer behavior, and product profitability.   
🚀 Key Features & Visualizations
High-Level KPIs: Instant visibility into core business metrics including Total Sales Amount , Total Profit , Total Quantity Sold , and Average Order Value.
Geographical Sales Distribution: Horizontal bar chart tracking Sum of Amount by State (highlighting top regions like Maharashtra, Madhya Pradesh, Delhi, Uttar Pradesh, and West Bengal).
Category & Payment Mode Breakdown: Donut charts illustrating the Sum of Quantity by Category (Clothing, Electronics, Furniture) and Sum of Quantity by Payment Mode (COD, UPI, Debit Card, EMI, Credit Card).
Temporal & Sub-Category Profitability: Monthly profit trends across January, February, and March alongside a granular breakdown of Sum of Profit by Sub-Category (Printers, Phones, Accessories, Bookcases, Saree).
Top Customers Analysis: Performance tracking for key buyers (Harivansh, Shiva, Madhav, Sarita, Madan Mohan).   Interactive Filtering: Dynamic quarter selectors (Qtr 1, Qtr 2, Qtr 3, Qtr 4) and global slicers for deep-dive analysis.
Tech Stack & ToolsTool: Microsoft Power BI (built using native aggregations and modeling features)   Data Transformation: Power Query   Design: Custom dark mode layout with clear visual hierarchy.
